# 🎓 Colegio de Montalban - OJT & Work Immersion Attendance System
A cloud-based QR Code Attendance Management System developed for **Colegio de Montalban** to streamline OJT and Work Immersion attendance tracking. The system provides real-time attendance logging, automated DTR generation, cloud storage, and administrative reporting through a secure and user-friendly web platform.

## 🚀 Quick Access
🔗 **Live App:** https://colegio-de-montalban-ojt-attendance-system.vercel.app  

## ✨ Features
- 📱 QR Code & Manual Attendance Scanning
- ☁️ Supabase Cloud Database Integration
- 🕒 Automated DTR and Hour Computation
- 🛡️ Attendance Validation & Anti-Duplicate Scanning
- 🚑 Emergency Logout Override System
- 👨‍💼 Admin Dashboard with Student Management
- 📊 CSV Export and Print-Ready Reports

## 🛠 Tech Stack
**Frontend:** HTML5, Tailwind CSS, JavaScript  
**Backend & Database:** Supabase  
**Hosting:** Vercel  
**Version Control:** Git & GitHub
